    How this dashboard is built
    1. A GitHub Actions job runs every 5 minutes, Monday to Friday, 13:00–21:59 UTC.
    2. It calls the Finnhub API (quotes, company news, profiles) and loads the results into Snowflake TKO_DB.RAW.
    3. Views in TKO_DB.MART shape the data for each card on this page.
    4. The same job exports those views as JSON to the data branch of github.com/gilkroin/tko-dashboard.
    5. A Claude scheduled task uploads the newest JSON files to this dashboard once an hour.

    Open Sources to see the file behind every number. Not investment advice.
